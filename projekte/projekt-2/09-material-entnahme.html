Material-Entnahme & Reste-Automatik

Das eigentliche Herzstück für die Aufgabe „Reste besser nutzen“: Beim Zuschnitt eines Artikels berechnet das System live die Restlänge und entscheidet automatisch, ob sie sich lohnt aufzuheben.

Quelle 05Lagerbestand_Excel_Datei_Stand_14.08.26.pdf · Modul G7_MaterialEntnahme_Logik · Formular frmMaterialEntnahme

Warum diese Seite eine eigene braucht

Auf den ersten Blick klingt „Reste“ nur nach einem zusätzlichen Excel-Blatt. Tatsächlich steckt dahinter eine eigene kleine Entscheidungslogik: Wird ein Stück Material teilweise verbraucht (z. B. ein 2 m langes Rohr, von dem nur 1,3 m gebraucht werden), berechnet das System die Restlänge automatisch, fragt bei sehr kurzen Resten nach, ob sie überhaupt noch lohnenswert sind, und bucht brauchbare Reste selbstständig in die Restebestand-Liste ein – ohne dass jemand von Hand nachträgt.

Der Dialog: Barcode scannen, Länge eingeben

Wird ein Stück-Barcode gescannt (mit Bindestrich, z. B. „VKBS0001-2“), lädt das Formular direkt dessen Länge. Wird nur der Gruppen-Barcode gescannt, füllt sich ein Dropdown mit allen verfügbaren Stücken dieser Gruppe zur Auswahl.

Sobald eine Zahl eingetippt wird, berechnet das Formular live die Restlänge (Ausgangslänge − genutzte Länge) und zeigt sie sofort an.

Ist der berechnete Rest kleiner als 1000 mm, fragt eine MsgBox gezielt nach, ob das Stück in den Schrott soll – oder ob es sich noch lohnt, es in die Reste-Liste aufzunehmen.

Ein Klick auf „Material entnehmen“ übergibt alle Werte an die eigentliche Logik im Modul G7 – das Formular selbst kennt die Lagerlogik gar nicht, es sammelt nur die Eingaben.

' Live-Berechnung, sobald der Nutzer die genutzte Länge eingibt
Private Sub txtGenutzt_Change()
    On Error Resume Next
    initLaenge = CDbl(txtInitialeLaenge.Value)
    genLaenge  = CDbl(txtGenutzt.Value)
    rest = initLaenge - genLaenge
    If rest >= 0 Then
        txtRestlaenge.Value = rest
    Else
        txtRestlaenge.Value = "Fehler (Genutzt > Initial)"
    End If
End Sub

Die Schrott-Grenze

Ein fest im Code hinterlegter Schwellenwert (1000 mm) unterscheidet automatisch zwischen einem Reststück, das sich noch zu lagern lohnt, und einem Abschnitt, der ohnehin im Müll landet. Erst unterhalb dieser Grenze wird überhaupt nachgefragt – bei längeren Resten landet das Stück ohne Rückfrage direkt in der Reste-Liste. 

' SCHROTT-PRÜFUNG – nur wenn ein kleiner Rest übrig bleibt
IstSchrott = False
If restL > 0 And restL < 1000 Then
    If MsgBox("Das berechnete Reststück ist nur " & restL & " mm lang." & vbCrLf & _
        "Soll es in den MÜLL/SCHROTT geworfen werden?" & vbCrLf & vbCrLf & _
        "(Klicken Sie 'Nein', um es in die Reste-Liste zu legen)", _
        vbYesNo + vbQuestion, "Schrott-Grenze unterschritten") = vbYes Then
        IstSchrott = True
    End If
End If

Was im Hintergrund passiert (ProzessMaterialEntnahme)

SchrittWas passiert
1 · Original-Stück findenÜber die zentrale Suchfunktion (Modul D) in der Ursprungstabelle lokalisieren.
2 · Menge reduzierenIst mehr als 1 Stück vorhanden, wird die Menge um 1 verringert; war es das letzte Stück, wird die ganze Zeile gelöscht.
3 · Reststück einbuchen (falls kein Schrott)Existiert bereits ein Reststück derselben Gruppe mit exakt gleicher Länge, wird nur dessen Menge um 1 erhöht – sonst wird eine komplett neue Zeile mit eigenem Barcode angelegt.
4 · Verlauf protokollierenEin Eintrag mit Typ „Verbrauch“ und der genutzten Länge (als negativer Wert) wird automatisch im Blatt „Verlauf“ ergänzt.
Gleiche Reste werden zusammengeführt statt dupliziert: Schneidet man zweimal ein 300-mm-Reststück vom selben Profil ab, landet das nicht als zwei Zeilen im System, sondern als eine Zeile mit Menge 2 – die Reste-Liste bleibt dadurch übersichtlich, auch wenn immer wieder ähnliche Reste anfallen.

Einordnung: die Buttons, die diese Logik auslösen

Auf dem Dashboard (siehe Tablet-Modus, Seite 8) gibt es getrennte Buttons für „Reste hinzufügen/löschen/bearbeiten“ – sie rufen exakt dieselben Funktionen wie bei vollständigen Artikeln auf, nur mit dem Parameter „Rest“ statt „Voll“ und dem Zielblatt „Reste“ statt „Artikel Liste“. Die Material-Entnahme-Logik auf dieser Seite ist der einzige Weg, wie automatisch – ohne manuellen Button-Klick auf „Reste hinzufügen“ – neue Resteinträge entstehen.
